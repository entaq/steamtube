# Emoji Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a polished, kid-safe AI emoji-combination game that deploys as static files plus Vercel Functions through the repository's existing Git-push workflow.

**Architecture:** A framework-free browser client owns collection state, interactions, local recipe caching, and offline fallbacks. Two CommonJS Vercel Functions call OpenAI for structured combination results and legendary sticker images while sharing strict validation helpers. Pure game and validation functions are covered by Node tests; the full workflow is covered by Playwright with mocked API responses.

**Tech Stack:** HTML5, CSS, browser ES modules, IndexedDB, Node.js Vercel Functions, OpenAI Responses and Image APIs, Node test runner, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-23-emoji-lab-design.md`

## Global Constraints

- Deploy through Vercel directly from Git with no static-site build step.
- Keep `OPENAI_API_KEY` exclusively in Vercel environment settings.
- Support children ages 8–10 without free-text prompts, chat, accounts, ads, or social features.
- Preserve ordinary gameplay when either AI endpoint is unavailable.
- Persist collection and recipes in `localStorage`; persist generated sticker blobs in IndexedDB.
- Make every drag action available through tap and keyboard controls.
- Honor `prefers-reduced-motion` and provide sound and motion toggles.
- Do not add a shared database in V1.
